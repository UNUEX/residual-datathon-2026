# Источники данных

Архив организаторов [STAT.DATATHON](https://datathon.stat.gov.kz/#/): `synthetic_microdata_2021-2024_20260921.tar.gz`.

Пути ниже указаны относительно распакованного архива.

| Файл | Использование |
|---|---|
| `MANIFEST.csv` | Размеры и перечень таблиц |
| `data-guide.html` | Структура данных, ключи и ограничения синтетики |
| `documentation/d002/2024/Структура файлов_D002_2024.xls` | GR21 — часть 2, вопрос 1; GR4 — часть 1, вопрос 4 |
| `documentation/d002/2024/Д002- каз,рус.pdf` | Шкалы 1–10, специальный код 89, коды достатка 1–6 |
| `documentation/d008/2024/D008_2024/Структура D008.doc` | NOMER, NOMP, KOL_CHL |
| `documentation/d006/2024/D006_deid/структураД006.doc` | Общая и жилая площадь, число комнат |
| `documentation/d004/2024/` | Структуры квартальных таблиц, коды участия REZ |

Дархан Медеуов, «Synthetic microdata for the datathon», семинар 28 сентября 2026 года, файл `datathon_synthetic_data.html`: метод синтеза, соединение D-форм внутри года, отсутствие межгодовой панели и ограничения статистических выводов.
