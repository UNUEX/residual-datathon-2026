Residual — анализ жилищных условий за 2024 год

Задача сотрудника
Подготовить внутреннюю справку: как различается медианная общая площадь
жилья на одного записанного члена домохозяйства в группах 1–2, 3–4 и 5+ человек.
ИИ составляет план по вопросу и подтверждённым метаданным. Расчёт делает
проверяемый Python-код после подтверждения специалистом.

Анализ выполнен на синтетическом наборе STAT.DATATHON 2026.
Результаты не являются официальными оценками населения Казахстана.

1. Подготовка (один раз для этой пары исходников)
Запустите start_residual.cmd, чтобы установилось окружение проекта.
В корне репозитория выполните в PowerShell:

  .venv\Scripts\python.exe -m src.prepare_competition --data-root "ПУТЬ_К_РАСПАКОВАННОМУ_АРХИВУ"

Для Linux/macOS замените .venv\Scripts\python.exe на .venv/bin/python.
Корень архива должен содержать d006, d008, documentation и data-guide.html.
Используются ровно d006/2024/rio_2024.csv и d008/2024/kontr_k.csv.
Скрипт ничего не загружает из сети, не меняет исходники и не обращается к ИИ.

Результат в private_outputs/competition_case:
  competition_2024.csv — одна строка на пригодное домохозяйство, без исходных ID;
  preparation_audit.json — определения, SHA-256 источников и кода,
    число совпадений/исключений, ограничения и контрольные агрегаты.
Исходные и подготовленные записи не следует добавлять в публичный репозиторий.

2. Работа в основном приложении
Откройте http://127.0.0.1:8766/, раздел «Данные».
Загрузите competition_2024.csv. Укажите название:
  «Синтетические конкурсные данные D006 + D008, 2024».
Период: 2024. Единица наблюдения: домохозяйство.
Отметьте «Это синтетические или учебные данные» в паспорте набора.
Десятичный разделитель: точка.
«Размер домохозяйства» — категория.
«Членов домохозяйства» — число, единица «чел.».
«Общая площадь», «Жилая площадь» — числа, единица «м²».
«Площадь на человека» — число, единица «м²/чел.».

В разделе «Исследование» задайте:
  Сравни медиану «Площадь на человека» по «Размер домохозяйства» за 2024 год.

Проверьте план: показатель «Площадь на человека», медиана,
группировка «Размер домохозяйства». Подтвердите расчёт.
Скачайте HTML-справку, результат CSV, описание JSON и Python со входным CSV.
Python из экспорта повторяет расчёт по подготовленной таблице.
Для полного воспроизведения от исходных форм сначала запустите подготовку выше.

Контроль для выданного архива synthetic_microdata_2021-2024_20260921:
  D006: 11 704 домохозяйства; D008: 41 821 человек в 12 000 домохозяйствах.
  Все D006 связались с D008; 296 карточек D008 не имеют строки D006.
  Исключены 46 записей с J_PL > OB_PL; других исключений нет.
  В анализе 11 658 домохозяйств:
    1–2 человека: 4 427 домохозяйств, медиана 37 м²/чел.;
    3–4 человека: 3 962 домохозяйства, медиана 18,666667 м²/чел.;
    5+ человек:   3 269 домохозяйств, медиана 12,666667 м²/чел.
Все подготовленные строки и эти медианы сверены независимым расчётом pandas
из исходных форм. При изменении источников ожидаемые значения могут измениться.

3. Откуда берутся поля и ограничения
data-guide.html описывает NOMER как ключ домохозяйства между формами одного года,
а NOMER + NOMP — как ключ человека. Ключи читаются текстом с ведущими нулями.
Сначала считаются уникальные люди в D008, затем размер соединяется с D006.
Так площади не размножаются на число членов семьи при объединении.
KOL_CHL должен совпадать с посчитанным составом во всех строках домохозяйства.
Дубликаты ключей и другой GOD прекращают подготовку. Отсутствующий состав
и несогласованное KOL_CHL исключаются с записью количества в аудит.

Определения площадей: документация D006, вопросы 3 и 4 и инструкция, пункт 7.
OB_PL — общая площадь, J_PL — жилая, квадратные метры в целых числах.
Используются только конечные положительные целые площади и J_PL <= OB_PL.
Последнее — правило проекта по смыслу определений, не приписываемое БНС
официальное контрольное соотношение. Значения не исправляются и не заполняются.
Служебные числовые коды других вопросов не анализируются.

«Площадь на человека» = OB_PL / число записанных членов домохозяйства.
Затем вычисляется медиана этих отношений по домохозяйствам каждой группы.
Это не отношение сумм и не медиана по всем отдельным людям. Группы придуманы
для демонстрации. Изменения состава в течение года не моделируются.
Число комнат здесь не используется и не влияет на отбор записей.

Синтез данных меняет зависимости между переменными. Веса, доверительные
интервалы и контроль раскрытия не применяются. Удельная площадь механически
зависит от размера состава, поэтому сравнение не доказывает причинный эффект.
Область применения MVP — проверяемая внутренняя описательная справка
по подготовленной таблице. Подготовка по документации остаётся явным шагом.
