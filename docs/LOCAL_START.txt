RESIDUAL — ЛОКАЛЬНЫЙ ЗАПУСК

КРАТКО
1. Python 3.11–3.13 с python.org (галочка Add python.exe to PATH).
2. start_residual.cmd — устанавливает зависимости, запускает приложение и браузер.
3. setup_local_ai.cmd — один раз загружает локальную Ollama и qwen3:1.7b.
4. Файл → выбор таблицы → паспорт столбцов → вопрос → подтверждение плана → справка.
Далее достаточно start_residual.cmd. Остановка: stop_residual.cmd.
Для локального запуска не нужны хостинг и платная подписка.

Быстрый старт: docs/QUICK_START.txt.
Основной конкурсный пример D006 + D008 через обычный импорт:
docs/COMPETITION_CASE.txt. Это подготовка одной таблицы и работа в главном
приложении, а не переход в исторический модуль /housing/.

ПЕРВЫЙ ЗАПУСК WINDOWS
Распакуйте весь репозиторий в папку с правом записи, например Documents/Residual.
Не запускайте файлы прямо внутри ZIP. Интернет нужен для первоначальной установки.
setup_local_ai.cmd запускается после start_residual.cmd. Окна показывают ход работы;
дождитесь окончания установки перед проверкой подключения модели.
CPU-вариант для Windows 10/11 x64: компоненты Ollama v0.40.3 и qwen3:1.7b,
около 1,5 ГБ загрузки и 3 ГБ места. Скорость ответа зависит от процессора и памяти.
Установщик проверяет CRC32 компонентов и цифровую подпись ollama.exe; хеш всего
архива при выборочной загрузке не проверяется. Манифест остаётся рядом с runtime.
setup_local_ai.cmd -WithGpu загружает полный ZIP и сверяет официальный SHA256;
для него подготовьте около 7 ГБ диска. Прерванную загрузку можно повторить.
Установщик не создаёт системную службу и не меняет системный PATH.

ПЕРВЫЙ РАСЧЁТ
Откройте http://127.0.0.1:8766/ и нажмите «Попробовать пример».
Во вкладке «Данные» тот же файл доступен через «Открыть пример Excel».
Файл examples/import/schools.xlsx: 24 вымышленные школы, 2025 год.
Лист «Школы (учебные данные)», заголовок в строке 1.
Паспорт: одна строка — школа; период — 2025; «Код школы» — идентификатор;
«Тип школы» — категория; «Учащиеся» и «Учителя» — числа, единица «человек».
Подтвердите описание. Проверьте подключение во вкладке «Модель»,
вернитесь во вкладку «Исследование» и спросите:
«Сравни среднее “Учащиеся” по “Тип школы” за 2025 год».
План должен содержать Учащиеся, среднее и группировку Тип школы.
Проверьте его и нажмите кнопку расчёта. Сохраните нужные результаты.

Другой пример: examples/import/budget.html, 12 вымышленных учреждений за 2025 год.
Выберите таблицу «Бюджет учреждений (учебные данные)», заголовок в строке 1.
Регион — категория; Расходы и Поступления — числа в тысячах тенге.
У Расходов десятичный разделитель — запятая. Вопрос: сумма расходов по регионам.
Эти примеры не являются официальной статистикой.

ПАСПОРТ И КОДЫ ПРОПУСКОВ
Перед расчётом подтвердите смысл каждой строки, названия, роли и единицы.
В разделе «Коды отсутствующих ответов» каждого числового/категориального
столбца укажите коды из его документации через точку с запятой.
Программа не угадывает специальные числовые коды. Совпадение текстовое:
89 и 89.0 различаются; регистр и пробелы по краям не учитываются.
Ноль и отрицательные числа считаются обычными значениями, если вы явно
не объявили их кодами пропусков. Не переносите коды между разными формами.
Для синтетического или учебного набора отметьте соответствующую галочку.
Встроенные неизменённые примеры также распознаются по содержимому.
Вопрос должен явно содержать одну операцию: среднее, медиану или сумму.

ГРАНИЦЫ
Одна таблица CSV/TSV, лист Excel (.xlsx/.xls) или таблица HTML/HTM.
До 10 МиБ, 50 000 строк, 100 исходных и 15 используемых столбцов.
Одна операция: среднее, медиана или сумма; до 5 показателей;
одна категориальная группировка, не более 30 групп, либо вся таблица.
Нет соединений, фильтров, весов, новых формул или прогнозов.
Для конкурсного случая есть отдельная воспроизводимая подготовка D006/D008
в одну таблицу; порядок, фильтры и ограничения описаны в COMPETITION_CASE.txt.
SPSS, Stata и Parquet пока нужно преобразовать в CSV или Excel.
Код Python/R и блокноты не загружаются для исполнения.

ПОВТОРЕНИЕ ЧИСЕЛ
В одной справке скачайте Python и «CSV для Python» в одну папку. Выполните:
python reproduce_table.py source.csv > result.json
Для этого достаточно Python 3.10+, без дополнительных библиотек и модели.
Код проверяет SHA-256 источника. source.csv — машинный источник с сохранёнными
значениями, включая возможный формулоподобный текст. Для просмотра в Excel
используйте отдельный CSV результата с экранированными текстовыми ячейками.
Чтобы проверить реакцию на данные, измените число в копии учебного файла,
загрузите её как новый набор и повторите среднее или сумму. Медиана от одной
правки может не измениться; старая справка сохраняет своё происхождение.

МОДЕЛЬ И ХРАНИЛИЩЕ
Приложение: http://127.0.0.1:8766/; локальная модель: http://127.0.0.1:11434.
Настройки модели общие с прежним жилищным модулем /housing/.
Модель получает вопрос и подтверждённые метаданные, но не строки или результаты.
Вопрос и названия сами могут содержать чувствительные сведения. Внешний API
требует явного разрешения и HTTPS; автоматического переключения в облако нет.
Ключ API остаётся в памяти до перезапуска. Данные и отчёты — в private_outputs/,
среда — .venv/, модель — private_outputs/models/. Эти папки не добавляются в Git.
Примеры нового импорта — examples/import/; старые жилищные CSV — examples/demo/.
Если своя Ollama уже запущена, используется она. Нужна версия 0.40.3 или новее:
приложение требует локальный источник модели и блокирует облачные алиасы.
stop_residual.cmd завершает только подтверждённые процессы этого проекта;
данные и модели при остановке сохраняются.

НЕ РАБОТАЕТ
Python not found: установите Python 3.11–3.13, включите PATH и повторите запуск.
Либо укажите путь: powershell -File start_residual.ps1 -PythonPath "C:\Path\Python312\python.exe"
Ошибка зависимостей: проверьте интернет и повторите start_residual.cmd.
Порт занят: powershell -File start_residual.ps1 -Port 8767
Остановка этого порта: powershell -File stop_residual.ps1 -Port 8767
Нет модели: дождитесь setup_local_ai.cmd и повторите проверку подключения.
Мало памяти: можно установить меньшую модель, например setup_local_ai.cmd -Model qwen3:0.6b,
и указать её имя в настройках; правильность её планов проверяется отдельно.
Нет пригодных чисел: проверьте выбранную таблицу, строку заголовков, роли и дробный разделитель.
Запрос требует уточнения: укажите операцию и точное название показателя.
Если модель выбрала лишний показатель, расчёт остановлен; проверьте новый план.
Без модели импорт работает, но свободный вопрос требует подключения; готовый ответ не подставляется.
Журналы: private_outputs/server-8766.stderr.log и private_outputs/ollama.stderr.log.

MACOS / LINUX
Python 3.11–3.13 и bash: bash start_residual.sh. На Linux может требоваться python3-venv.
Установите Ollama с https://ollama.com/download; затем ollama pull qwen3:1.7b.
Для запуска модели без облака: OLLAMA_NO_CLOUD=1 ollama serve.
Ctrl+C в терминале останавливает приложение. Эти системы отдельно не проверялись.
