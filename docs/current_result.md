# Результаты

Проверены 52 таблицы D за 2024 год. Размеры совпадают с `MANIFEST.csv`; ключи домохозяйств согласованы с D008.

| Показатель | Значение |
|---|---:|
| Домохозяйства в D008 | 12 000 |
| Члены домохозяйств в D008 | 41 821 |
| Общая база D008 + D006 + D002 | 11 674 |
| Низкая самооценка достатка в D002, GR21 = 1–2 | 109 из 11 931 (0,91%) |
| Низкая самооценка достатка в общей базе | 107 из 11 674 |
| Участие во всех четырёх кварталах D004 среди общей базы | 11 408 |
| Низкая самооценка достатка среди участников всех кварталов | 104 из 11 408 |

В GR4 код 89 означает «не применимо / затрудняюсь ответить». После его исключения средняя оценка финансового положения составляет 7,15 вместо 9,25.

Из-за редкости GR21 = 1–2 правило «всегда выбирать остальные ответы» даёт 99,09% accuracy на полной D002. Для оценки модели выбрана average precision, дополнительно — precision и recall.

D004 содержит расходы, доходы, займы и производство. Общая сумма расходов пока не рассчитана. Участие в квартальном опросе не означает заполнения всех разделов; отсутствие записи не считается нулём.

Все показатели невзвешенные и относятся к синтетической выборке. Низкая самооценка достатка не является официальным статусом бедности. Модели пока не обучены.
