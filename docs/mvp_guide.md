# Отдельный модуль контроля качества

Модуль `/quality/` сохраняет прежний сценарий разбора жилищных данных D006 + D008 за 2024 год. Основной табличный ассистент и его запуск описаны в [README](../README.md) и [быстром старте](QUICK_START.txt).

## Рабочий процесс

1. Запустите `start_residual.cmd` и откройте [контроль качества](http://127.0.0.1:8766/quality/).
2. Загрузите CSV двух форм одного периода. Программа проверит структуру, ключи и связь домохозяйств.
3. Откройте случай в очереди и сопоставьте значения, условие проверки и основание из документации.
4. Сохраните решение с комментарием либо подготовьте черновик запроса на сверку. Черновик автоматически не отправляется.
5. После уточнения источника загрузите следующую версию пакета и сравните изменения. Старые версии и решения сохраняются; журнал и сравнение выгружаются.

## Пример интерпретации

Если жилая площадь превышает общую, программа показывает смысловое противоречие. По нему нельзя определить, какое из двух значений верно. Требуется сверка с первичным источником; автоматического исправления нет. Основание определения площадей — пункт 7 инструкции D006.

Редкая запись без такого противоречия может быть допустимой. Статистический балл задаёт порядок просмотра и не подтверждает ошибку. Центральные 50% массива служат описательным ориентиром, а не нормативным диапазоном.

## Методы

| Механизм | Назначение | Ограничение |
|---|---|---|
| Проверяемые условия | Пропуски, противоречия площадей, несогласованный состав | Не определяют правильное значение |
| Робастное ранжирование | Отклонения от распределения признаков текущего пакета | Редкость не означает ошибку |
| Isolation Forest | Дополнительные кандидаты вне основной очереди | Преимущество над простым методом не подтверждено |
| Помощник по случаю | Факты, выдержки документации и черновик уточнения | Фиксированные действия; языковая модель здесь не используется |

Процентиль балла не является вероятностью ошибки. Эксперимент проводился на известных искусственных изменениях синтетического массива. Его результаты и отрицательный результат сравнения ML сохранены в [отчёте](current_result.md), [методике](methodology.md) и [протоколе](benchmark_protocol.txt).

## Границы

Поддерживаются только две указанные формы одного года. Синтетические данные могут отличаться от исходных по связям между переменными. Проверки проекта не являются утверждённым ведомственным регламентом. Полезность на экспертно размеченных реальных ошибках и экономия времени специалиста не измерены; ведомственный пилот не проводился.

Хранение локальных версий не заменяет систему управления доступом, резервного копирования и защиты статистической конфиденциальности. Сценарий предназначен для одного локального пользователя и разрешённых к обработке данных.
