# Residual

Residual — локальный инструмент контроля качества статистических микроданных. Он объединяет проверяемые правила с `Isolation Forest`, формирует очередь подозрительных записей и сохраняет решение аналитика. Исходные CSV остаются без изменений.

Прототип работает на синтетических данных БНС Казахстана за 2024 год: форма D006 (жильё) связывается с D008 (состав домохозяйства) по ключу `NOMER`.

## Результат

- Проверено 11 704 жилищных записи.
- 46 записей нарушают условие `жилая площадь ≤ общая площадь`.
- Сформирована очередь из 250 записей: 46 сигналов правил и 204 кандидата модели.
- При просмотре 10% тестовой выборки правила с ML находят в среднем 81,9% внесённых искажений; правила со случайным порядком — 37,9%.
- Простой робастный метод нашёл 100% внесённых искажений. Поэтому приложение показывает сравнение методов и не выдаёт ML за лучший метод без подтверждения.

## Запуск

Python 3.11+. Распакуйте архив `synthetic_microdata_2021-2024_20260921.tar.gz` рядом с репозиторием.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m src.quality --data-dir "../synthetic_microdata_2021-2024_20260921"
python -m src.serve --port 8765
```

Откройте `http://127.0.0.1:8765`. Агрегированные результаты записываются в `reports/`; локальная очередь с идентификаторами и решения аналитика — в игнорируемую Git папку `private_outputs/`. Микроданные в репозиторий не включены.

## Структура

- `app/` — интерфейс рабочего места аналитика.
- `src/quality.py` — подготовка признаков, правила, модель и эксперимент.
- `src/serve.py` — локальный сервер и сохранение решений.
- `tests/` — проверки ключей, специальных кодов и ML-конвейера.
- `reports/` — агрегированные воспроизводимые результаты.
- `docs/` — выводы, методология и источники.
