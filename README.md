# Residual

Исследуем, помогают ли данные о расходах распознавать низкую самооценку материального достатка домохозяйств. Используем синтетические данные БНС Казахстана за 2024 год: состав семьи (D008), жильё (D006), самооценки (D002) и бюджет (D004).

Выполнены описательный анализ и проверка данных. Модели пока не обучены.

[Результаты](docs/current_result.md) · [Методология](docs/methodology.md) · [Источники](docs/sources.md)

## Запуск

Python 3.11+. Распакуйте архив `synthetic_microdata_2021-2024_20260921.tar.gz` вне репозитория. Путь в `--data-dir` должен содержать `MANIFEST.csv` и папки `d002`, `d004`, `d006`, `d008` с данными за 2024 год.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m src.eda --data-dir "../synthetic_microdata_2021-2024_20260921"
python -m src.budget_audit --data-dir "../synthetic_microdata_2021-2024_20260921"
```

Результаты записываются в `reports/`; другой каталог задаётся через `--output-dir`. Исходные микроданные в репозиторий не включены.

## Структура

- `src/` — проверка таблиц, ключей, специальных кодов и покрытия опросов.
- `tests/` — проверки обработки кодов и ключей.
- `reports/` — агрегированные результаты расчётов.
- `docs/` — результаты, методология и источники.
